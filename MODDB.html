Respawn Tools

Respawn Tools is a practical mod for Vintage Story, designed to improve the experience of death and revival in-game. It introduces the Respawn Beacon block, which lets players choose an alternate respawn point, and the Respawn Tablet item, which can save a player from death.

These features offer server owners and players greater flexibility and control over respawn mechanics, making gameplay more forgiving and strategic without compromising challenge.

Features

Mod Settings

(Default Hotkey: F8 )

Provides easy access to all settings, within all features of the mod.

  • Menu for server administrators only
  • Fully custom GUI with settings for all features
  • Links for support, and further information

Administrators are automatically granted all Respawn Tools privileges. The beacon and tablet use privileges are also granted to every server role by default; other beacon actions require their listed privileges. In Creative mode, beacon placement, configuration, and breaking do not require those action privileges. Server owners can adjust privileges for each role in the server's permissions settings.

Respawn Beacons

The Respawn Beacon is a placeable block that provides an alternate respawn point. When a player dies within range of an enabled beacon, they can choose Respawn at Beacon on the death screen. The nearest eligible beacon is used; if none is available, the player's normal respawn point is used. An enabled beacon emits ambient sound and light, and plays a sound and particle effect when used.

  • Sneak-right-click a placed beacon to open its settings. This requires respawntools.beacons.configure.

Beacon Settings

  • Enabled: Off by default. Turn on the beacon to make it an available respawn point.
  • Radius: 128 blocks by default; configurable from 0 to 1,280 blocks. The range is horizontal.
  • Ambient Volume: 100% by default; configurable from 0% to 100%.
  • Respawn Volume: 100% by default; configurable from 0% to 100%.
  • Craftable: A server setting, enabled by default. Administrators can disable the recipe; the beacon remains available in the Creative menu.

Beacon Privileges

  • respawntools.beacons.place — place beacons.
  • respawntools.beacons.configure — open a placed beacon's settings.
  • respawntools.beacons.use — see and select the beacon respawn option, and use an eligible beacon.
  • respawntools.beacons.break — break beacons.

Respawn Tablets

The Respawn Tablet automatically saves its holder from death when it is in their main hand, off hand, backpack, or selected hotbar slot. Each activation consumes one charge, and the tablet is consumed when it runs out. It plays a sound and particle effect when activated.

Tablet Settings

  • Craftable: A server setting, enabled by default. Administrators can disable the recipe; the tablet remains available in the Creative menu.
  • Charges: 1 by default; configurable from 1 to 10 charges per tablet.

Tablet Privilege

  • respawntools.tablets.use — activate Respawn Tablets.
